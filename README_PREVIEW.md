# СУПЕРМЕН Terminal — v3

Сборка сделана поверх исходной HTML/JS CRM/терминала.

## Что изменено на главном экране
- два варианта стрижки: «Под насадку — 500 ₽» и «Стрижка — 1000 ₽»;
- компактная шапка без дублирования навигации;
- весь основной экран рассчитан на работу без вертикального скролла на терминале;
- карточки стали ниже и плотнее, с горизонтальной компоновкой;
- убрана красная рамка «предвыбранной» стрижки;
- сохранено подтверждение услуги в модальном окне;
- сохранена служебная логика старой CRM.

## Сохранено из старой CRM
- dispatcher.js и WebSocket-механика;
- переход на client_phone.html;
- extras.html / actions.html / market;
- служебный PIN по двойному нажатию на логотип;
- открытие/закрытие смены;
- остальные существующие HTML/JS/CSS файлы.

## GitHub Pages
В корне сборки есть index.html, который перенаправляет на `terminal/html/index.html`.
Можно загрузить содержимое архива в корень репозитория.
