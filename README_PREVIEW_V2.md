# СУПЕРМЕН — терминал v2

Сборка сделана **на базе исходного `terminal.zip`**. Внутренняя структура, старые HTML-экраны, `dispatcher.js`, `configuration.js`, переходы и служебное PIN-окно сохранены.

## Что изменено в v2

- Полностью заменен только первый экран `terminal/html/index.html`.
- Добавлен стиль `terminal/html/css/home-v2.css`.
- Выбор 8 стрижек заменен на 2 варианта:
  - код `a`, ID 1: **ПОД НАСАДКУ — 500 ₽**;
  - код `e`, ID 5: **СТРИЖКА — 1000 ₽**.
- `Доп. услуги`, `Акции`, `Супермаркет`, двойной клик по логотипу для PIN, WebSocket dispatcher и переход на `client_phone.html` сохранены.
- Добавлен модальный экран подтверждения услуги перед переходом на телефон клиента.
- В корне есть `index.html`, который нужен только для GitHub Pages и открывает настоящий `terminal/html/index.html`.

## Важно перед боевым запуском

В этой версии для прототипа сохранены существующие сервисные ID: `1` и `5`. Названия и цены в `services.cfg` изменены. Перед установкой в салон нужно подтвердить, какие ID должна принимать серверная часть для новых тарифов 500/1000 ₽.

Исходный конфиг сохранен рядом как:
`terminal/src/resources/services.legacy.cfg`

## GitHub Pages

Загрузить **содержимое папки `superman-terminal-v2` в корень репозитория** и оставить Pages на `main / (root)`.
